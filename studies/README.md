# Studies and Research Material

This directory keeps lab evidence and evaluation scenarios separate from the user-facing application.

## Contents

- `liscere/` - contextual evaluation scenarios for the semantic policy layer, including the Modbus/TCP control pair where the same sensitive configuration write is evaluated differently in production and during a declared maintenance window.
- `chapter4_modbus_tcp_test_log.md` - consolidated chapter 4 Modbus/TCP validation log.
- `evidence/` - raw evidence exports, benchmark outputs, and screenshots.

These files support reproducibility and document the lab's validation history. They are not imported by the web app or required for users to run the dashboard or download the agent.
