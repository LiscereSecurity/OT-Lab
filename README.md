# OT-Lab (archived)

This repository preserves the Docker-based laboratory used for the Liscere technical report
LTR-2026-03 (grammar learning and phase inference over Modbus/TCP): the OpenPLC and FUXA
containers, the seed projects, the FastAPI backend with its declarative rules, the Modbus proxy,
the scenario pack and the evidence collected for the report. It is the tree of the `legacy-engine-v1`
tag of the former engine repository, published as a single commit and kept read-only.

The Liscere observer itself (the passive engine that infers the process state and judges whether
each supervisory command is coherent with it) is developed privately. Access requests:
research@liscere.com.
